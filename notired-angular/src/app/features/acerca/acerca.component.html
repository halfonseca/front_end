Acerca de NotiRed

NotiRed es una plataforma web de noticias (periódico digital) desarrollada como aplicación funcional completa en Angular. Permite explorar el catálogo, ver el detalle, guardar favoritos con localStorage, contactar con formulario validado y gestionar noticias con un mini-CRUD (crear / eliminar).

Componentes y binding implementados

  • 9 componentes: header, footer, home, listado, detalle, favoritos, contacto, acerca + reutilizable news-card (@Input/@Output).
  • Interpolación: {{ '{' }}{{ '{' }} noticia.titulo {{ '}' }}{{ '}' }}, contadores y mensajes.
  • Property binding: [noticia], [routerLink], [class.on], [formGroup].
  • Event binding: (click), (ngSubmit), (favorito), (eliminar).
  • Two-way binding: [(ngModel)] en búsqueda y newsletter; formControlName en formularios reactivos.
  • Routing: 7 rutas + comodín; detalle con parámetro :id.
  • Servicios + HttpClient + RxJS: carga del JSON, BehaviorSubject para el badge de favoritos.

Ficha del proyecto
